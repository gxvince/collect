# 删除历史副本设计

## 目标

删除 Git 已跟踪、未被活跃入口或模块引用的历史副本，降低仓库体积，不改变运行行为。

## 范围

- 删除文件名包含 `-vince` 的已跟踪文件。
- 删除 `backend/schema.sql.bak`。
- 保留活跃文件、用户现有改动及未跟踪的 `custom-api-plugin copy.php`。

## 验收

- 删除前再次确认目标均由 Git 跟踪且未被活跃代码引用。
- 运行后端单元测试和端到端测试。
- 提交只包含本规格指定的历史副本删除，不包含用户现有改动。

## 回滚

删除项均存在于 Git 历史，可通过回退本批提交恢复。
